# Propostas — FoodHub

Repositório privado com propostas comerciais e materiais de apoio para a primeira conversa com a compliance.

## Estrutura

- `/propostas/` — propostas comerciais em HTML/PDF
- `/apresentacoes/` — apresentações e decks
- `/contratos/` — contratos e termos
- `/anexos/` — materiais complementares

## Acesso

Este repositório é privado. Apenas o cliente e a equipe autorizada têm acesso.
