🧩 Componentes · responsabilidades

com.hermes.supervisor
Único launchd. Garante que hermesctl start rode sempre. Se o backend cair, relaunch em 10s.
hermesctl
CLI em ~/hermes-ops/bin/. Comandos: mission, start, stop, status, baseline, lock, backoff, session, painel, runbook, privacy.
server.js
Backend ESM. Baileys + fila + scheduler + API. Lock singleton em /tmp/hermes-8420.lock. Backoff exponencial no reconnect.
agent-watchdog.mjs
60s. Lê :8420 + WhatsApp + Ollama. Escreve state/live.json. Base do KPI no painel.
privacy-hook.mjs
120s. Varre logs/backend.out.log por /\d{10,13}/ + prompt|ollama. Se ambos → violação. Escreve state/privacy.json.
painel :8430
Dois HTMLs: evolucao.html (timeline) + arquitetura.html (este). Lê state/*.json. Nunca expõe leads.
Ollama (local)
KEEP_ALIVE=0. Modelos carregam sob demanda. Nunca recebe prompt com leads. 18 MB ocioso.
Singleton lock
/tmp/hermes-8420.lock com PID + timestamp. Injetado por patch ESM HERMES-SINGLETON no topo do server.js.
