# Central de Prospecção — WhatsApp

## Objetivo
Mapear contatos públicos de WhatsApp de empresas-alvo e gerar uma página HTML centralizada para prospecção.

## Estrutura
- `index.html` — interface pública
- `data/empresas.json` — base de dados
- `assets/css/style.css` — estilos
- `assets/js/app.js` — lógica
- `docs/metodologia.md` — documentação
- `logs/coleta.md` — histórico de coleta

## Como usar
Abra `index.html` após publicar o GitHub Pages.

## Como contribuir
Edite `data/empresas.json` e faça commit.
