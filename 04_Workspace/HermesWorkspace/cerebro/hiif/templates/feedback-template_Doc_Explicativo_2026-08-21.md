# COMBINAÇÃO DE REFERÊNCIAS + FEEDBACK — HIIF

Formato estruturado para adicionar novas referências e/ou fornecer feedback sobre existentes.

---

## 1. NOVAS REFERÊNCIAS

Para propor uma nova referência, preencha:

```markdown
### [NOME DO PROJETO]
- URL: 
- Categoria: 
- Tipo: 
- Fonte: 
- O que chamou atenção: 
- Padrões identificados (se houver):
```

## 2. FEEDBACK SOBRE REFERÊNCIAS EXISTENTES

Para dar feedback sobre uma referência já catalogada, use o ID:

```markdown
### Feedback sobre [ID] — [NOME]
- Concorda com a análise? 
- O que mudaria?
- Padrões adicionais observados:
- Classificação sugerida:
```

## 3. FEEDBACK SOBRE O HIIF

Para sugerir melhorias no próprio framework:

```markdown
### [TEMA DO FEEDBACK]
- O que está faltando?
- O que deveria ser removido?
- Sugestão de melhoria:
```

## 4. FEEDBACK SOBRE PADRÕES

Para sugerir novos padrões ou evoluções:

```markdown
### [NOME DO PADRÃO]
- Problema que resolve:
- Quando usar / não usar:
- Exemplos (se houver):
```

## 5. FEEDBACK SOBRE TECNOLOGIAS

Para atualizar o stack tecnológico:

```markdown
### [TECNOLOGIA]
- Projeto onde foi observada:
- Classificação atual: 
- Nova classificação sugerida:
- Motivo da mudança:
```

---

## Como usar

1. Copie o formato aplicável acima
2. Preencha com suas observações
3. Envie para análise
4. O HIIF será atualizado com base no seu feedback

Critério de curadoria continua valendo: se não melhora o HIIF, descarta.
