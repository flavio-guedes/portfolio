# HIIF — Avaliação de Descobertas (2026-08-21)

Critério: isso melhora o HIIF?

## Linear
- Classificação: Novo padrão + Nova referência
- Rationale: command palette central como navegação primária é padrão novo na biblioteca. Linear é exemplo confirmado de uso em produção com alto impacto.

## Vercel
- Classificação: Nova referência
- Rationale: landing page de referência, mas não introduz novo padrão estrutural além do já catalogado Hero-Feature-Proof-CTA.

## Resend
- Classificação: Nova referência + Tendência temporária (brutalist minimal)
- Rationale: brutalist funcional é tendência; se consolidar, vira padrão. Por enquanto, registrar como tendência.

## Notion Dashboard Kit
- Classificação: Novo padrão
- Rationale: bento grid modular é padrão novo, não existia na biblioteca antes.

## AI Command Center
- Classificação: Novo padrão + Insight experimental
- Rationale: command-driven AI center combina command palette + dados em tempo real. Padrão novo. Insight: IA contextual como centro de comando.

## Raycast
- Classificação: Evolução de padrão existente + Nova referência
- Rationale: spatial navigation/spaces é evolução do command palette. Já tínhamos command palette, agora refinamos para spatial.

## Stripe Dashboard
- Classificação: Nova referência
- Rationale: referência de dashboard financeiro. Padrões de componentes já catalogados (KPI, tables, filters).

## Loom
- Classificação: Nova referência
- Rationale: landing page editorial. Padrões já conhecidos.

## LottieFiles
- Classificação: Nova técnica + Nova referência
- Rationale: Lottie/Rive como animação funcional (não decorativa) é técnica nova no HIIF.

## Excalidraw
- Classificação: Insight experimental + Nova referência
- Rationale: canvas espacial como interface principal é insight experimental. Pode evoluir para padrão se replicado.

## Arc Browser
- Classificação: Evolução de padrão existente
- Rationale: spaces como evolução do spatial navigation. Já tínhamos spatial navigation, agora refinamos para contexto agrupado.

## Conclusão
- 3 novos padrões: Command Palette Central, Bento Grid Modular, Command-Driven AI Center
- 2 evoluções: Spatial Navigation/Spaces, Central Command Bar
- 1 nova técnica: Lottie/Rive funcional
- 1 insight experimental: Canvas espacial como interface principal
- 4 novas referências: Vercel, Stripe Dashboard, Loom, Excalidraw
- 1 tendência temporária: Brutalist minimal

Próximo passo: consolidar novos padrões na biblioteca e remover referências sem padrão associado.
