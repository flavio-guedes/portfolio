# HIIF — Workflow de Manutenção Contínua

## Objetivo
Transformar referências externas em princípios reutilizáveis sem apenas acumular dados.

## Passos recomendados
1. Selecionar 1 a 3 fontes por ciclo
2. Coletar candidatos relevantes
3. Preencher template de análise
4. Extrair conceitos centrais e padrões
5. Atualizar biblioteca de padrões
6. Verificar aplicabilidade nos projetos ativos

## Regras
- Não pesquise apenas para acumular referências
- Priorize projetos premiados e inovadores
- Sempre classifique tecnologias como CONFIRMADA | PROVÁVEL | INFERIDA | DESCONHECIDA
- Documente por que a interface funciona, não apenas como parece

## Comandos úteis
- Coletar referência: usar `reference_collector.py`
- Analisar referências existentes: usar `reference_scraper.py`
- Template de análise: `templates/reference-analysis-template.md`
