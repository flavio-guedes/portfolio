# EPQ — CREATIVE GOVERNANCE
**Regras de Marca · Compliance · Decisão · Controle**
Versão 1.0 — Agosto/2026

---

## 1. MISSÃO
Garantir que toda peça publicada mantenha o DNA da EPQ e não gere risco de inconsistência de marca.

## 2. FONTES OFICIAIS
- Guia Visual EPQ — Atualização
- Playbook de Marketing EPQ
- **Modelo de Briefing EPQ — pasta Drive: `04 - Modelos de Briefing` (obrigatório)**
- EPQ Creative Bible
- EPQ Visual Guide
- EPQ Voice Guide
- EPQ KV Guide
- Peças aprovadas na pasta de criação

## 3. HIERARQUIA DE DECISÃO
Em caso de conflito:
1. Guia Visual EPQ atualizado
2. Playbook Marketing EPQ
3. Creative Bible
4. Peça aprovada anterior
5. Decisão documentada em briefing

## 4. RISCOS DE INCONSISTÊNCIA
- Cores fora da paleta
- Tipografia não autorizada
- Logo sem área de proteção
- Respiro desrespeitado
- CTA agressivo
- Copy sem conexão estratégica
- Imagem sem espaço para texto
- Peça sem objetivo/funil/público definidos

## 5. PROCESSO DE APROVAÇÃO
1. **Briefing preenchido e aprovado** — etapa obrigatória e não negociável
2. Copy validada
3. Direção de arte validada
4. Checklist de governança aplicada
5. Aprovação final documentada

Regra: sem briefing aprovado, a peça não segue para criação.

## 6. MATRIZ DE CONSISTÊNCIA

| Elemento | Regra |
|---------|-------|
| Logo | Obrigatória, proporcional, com área de proteção |
| Cores | Conforme Guia Visual |
| Tipografia | Conforme Visual Guide |
| KV | Conforme campanha |
| Tom de voz | Conforme público/canal |
| Fotografia | Conforme direção |
| Copy | Conforme objetivo |
| CTA | Conforme estágio |
| Formato | Conforme canal |
| Concurso | Conforme contexto |
| Público | Conforme persona |

## 7. DOCUMENTAÇÃO DE DESVIOS
Qualquer desvio deve ser registrado no briefing com:
- Motivo estratégico
- Impacto esperado
- Alternativa considerada
- Aprovação explícita

## 8. GOVERNANZA CONTÍNUA
- Revisão quinzenal de peças publicadas
- Atualização deste documento quando houver nova regra oficial
- Manutenção da pasta de referências atualizada

## 9. ALERTA
Se uma solicitação sair do sistema, não execute cegamente.
Identifique o risco, explique a regra quebrada e proponha alternativa alinhada.

## 10. PADRÃO DE QUALIDADE
“Mesmo sem ver o logo, alguém deve reconhecer: isso é EPQ.”
