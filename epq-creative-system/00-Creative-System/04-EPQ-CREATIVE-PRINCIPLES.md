# EPQ — CREATIVE PRINCIPLES
**Princípios de Direção Criativa · Governança · Decisão**
Versão 1.0 — Agosto/2026

---

## 1. PRINCÍPIOS FUNDAMENTAIS

### 1.1 Briefing primeiro
Todo projeto deve ser iniciado pelo preenchimento completo do **Modelo de Briefing EPQ**.
Sem briefing aprovado, não existe criação.

### 1.2 Inteligência antes de arte
Toda peça nasce de objetivo, público, insight, mensagem e formato.
Depois vem a direção de arte. Nunca o inverso.

### 1.2 Uma ideia por peça
Uma peça com 5 mensagens não tem mensagem.

### 1.3 Estratégia antes de copy
Copy nasce da estratégia, não do espaço visual.

### 1.4 Consistência antes de criatividade
Criatividade que descaracteriza a marca gera ruído, não resultado.

### 1.5 Adaptação ≠ Descaracterização
Todo desvio de regra deve ser estratégico, documentado e aprovado.

## 2. CHECKLIST PRÉ-PUBLICAÇÃO

### Estratégia
- [ ] Sei por que essa peça existe
- [ ] Sei em qual etapa do funil ela está
- [ ] Sei quem quero atingir
- [ ] Sei o comportamento que quero provocar

### Copy
- [ ] Hook claro
- [ ] Uma ideia central
- [ ] CTA correspondente à etapa

### Design
- [ ] Hierarquia clara
- [ ] Identidade EPQ preservada
- [ ] Sem excesso de informação
- [ ] Respiro respeitado (Stories: 20% topo/footer)

### Operação
- [ ] Link/WhatsApp corretos
- [ ] Rastreamento definido
- [ ] Responsável definido

## 3. NÃO PUBLICAR
- Sem objetivo
- Sem público
- Sem etapa de funil
- Sem CTA quando necessário
- Promessa não validada
- Métricas inventadas
- Urgência falsa
- Case sem autorização
- Informação jurídica não validada
- Conteúdo confundido com oferta

## 4. MATRIZ DE DECISÃO

| Critério | Pergunta |
|---------|---------|
| Marca | Parece EPQ? |
| Mensagem | Está clara em 3 segundos? |
| Público | Foi feita para a pessoa certa? |
| Contexto | Adequada ao concurso/assunto? |
| Criatividade | Existe ideia ou só decoração? |
| Impacto | Chama atenção no feed? |
| Legibilidade | Mensagem rápida de entender? |
| Consistência | Alinhada ao KV? |
| Conversão | Existe ação clara? |
| Escala | Variações mantêm identidade? |

Classificação:
APROVADO / APROVADO COM AJUSTES / REPROVADO

## 5. BRIEFING EM CADA PROJETO
Em cada projeto, gere um briefing para seguir.
Ele documenta: objetivo, formato, tema, público, mensagem, headline, CTA, direção visual e regras.
Sem ele, a peça não tem governança.

## 6. CRITÉRIO FINAL
“Se não houver dado real, use —.”
Nunca inventar métricas, cases ou promessas.
