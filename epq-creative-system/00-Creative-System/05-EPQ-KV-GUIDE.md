# EPQ — KV GUIDE
**Key Visual · DNA Visual · Aplicação de Campanha**
Versão 1.0 — Agosto/2026

---

## 1. DEFINIÇÃO
O KV é o DNA visual das campanhas e materiais da EPQ.
Ele não é só uma imagem bonita. É o sistema visual que garante reconhecimento imediato.

## 2. ELEMENTOS OBRIGATÓRIOS
- Identidade EPQ clara
- Hierarquia de leitura em até 3 níveis
- Espaço negativo suficiente
- Cores dentro da paleta oficial
- Tratamento visual coerente com o tom

## 3. ELEMENTOS VARIÁVEIS
- Protagonista: aluno real ou natural
- Cenário: contexto do concurso ou ambiente de estudo
- Dados: números, estatísticas, depoimentos
- Elementos técnicos: gráficos, ícones, UI

## 4. ELEMENTOS PROIBIDOS
- Banco de imagem genérico
- Modelos publicitários artificiais
- CTA agressivo sem contexto
- Gradientes neon exagerados
- Logo deformado ou pequeno

## 5. COMPOSIÇÃO
Estrutura preferencial:
1. Topo: marca ou contexto
2. Centro: ideia central + imagem/prova
3. Base: CTA ou informação seguinte

Para Stories: respeitar 20% respiro no topo e 20% no footer.

## 6. HIERARQUIA
1. Impacto visual
2. Contexto textual
3. Prova/dado
4. Ação

## 7. TRATAMENTO DE IMAGEM
- Contraste elevado sem perder naturalidade
- Color grading azulado/ciano quando houver tech/método
- Luz noturna/estudiosa quando houver esforço
- Nitidez no protagonista, leve bokeh no fundo

## 8. APLICAÇÃO POR CANAL
- Feed: impacto + leitura completa
- Stories: velocidade + ação + respiro
- Reels: retenção + narrativa visual
- Anúncio: atenção + benefício + CTA
- Apresentação: clareza + autoridade
- Pedagógico: organização + legibilidade

## 9. ADAPTAÇÃO POR CONCURSO
Cada concurso pode ganhar referências visuais específicas:
- PF/PRF/PC: uniforms, brasões, cenários institucionais com moderação
- Militares: disciplina, hierarquia, seriedade
- Outros: focar na dor genérica e na jornada

Nunca usar símbolos, brasões ou uniformes de forma indevida ou sensacionalista.

## 10. REGRA DE OURO DO KV
“ADAPTAR ≠ DESCARACTERIZAR”
Se uma adaptação compromete o reconhecimento EPQ, não é adaptação. É outra marca.
