# HIIF CUSTOM EVOLUTION

Camada de evolução customizada do framework, combinando inteligência externa e do usuário.

## Conceito
O HIIF base é enriquecido por duas fontes:

- **FONTE A — Inteligência Externa**: referências e padrões de sites internacionais, premiações e galerias.
- **FONTE B — Inteligência do Usuário**: solicitações, preferências, ajustes, críticas e decisões tomadas ao longo dos projetos.

A combinação produz a **Custom Evolution**: um framework adaptado à realidade específica do usuário, sem perder o alinhamento com o que há de mais relevante no mercado global.

## Estrutura

### 1. Evidência Externa
- Referência analisada
- Padrão identificado
- Classificação HIIF
- Relevância para o contexto do usuário

### 2. Decisão do Usuário
- Solicitação explícita
- Preferência declarada
- Ajuste solicitado
- Crítica ou feedback
- Decisão tomada em projeto

### 3. Evolução Customizada
- Novo padrão proprietário
- Adaptação de padrão existente
- Exceção justificada
- Regra de projeto específica
- Stack preferido
- Direção de arte preferida

## Princípios
- Nenhuma evolução customizada descarta a base — ela é um acréscimo qualificado.
- Toda evolução deve ser rastreável à sua fonte (A ou B).
- Se a inteligência externa contradiz a do usuário, a do usuário prevalece.
- O objetivo é reduzir repetição de decisões e acelerar entregas futuras.

## Aplicação
- Novos projetos herdam a base + custom evolutions aplicáveis.
- Projetos existentes podem ser auditados para identificar oportunidades de aplicação.
- A camada evolui continuamente com cada nova referência e cada novo feedback.
