# EPQ — AI IMAGE PROMPT SYSTEM
**Direção de Arte para IA · Prompts Profissionais · Controle de Marca**
Versão 1.0 — Agosto/2026

---

## 1. REGRA
Nunca enviar prompts genéricos.
Toda imagem gerada por IA deve ser construída para a peça, não para ser apenas “bonita”.

## 2. ESTRUTURA OBRIGATÓRIA DO PROMPT
1. Objetivo da imagem
2. Público-alvo
3. Contexto
4. Composição
5. Enquadramento
6. Câmera/lente
7. Iluminação
8. Ambiente
9. Personagem
10. Expressão/figurino
11. Direção fotográfica
12. Profundidade
13. Textura
14. Cores/paleta
15. Elementos de marca
16. Espaço negativo
17. Aplicação futura de texto
18. Formato
19. Referência estética
20. Negativos

## 3. EXEMPLOS POR TIPO

### Story — Topo de funil
Prompt base:
“Story vertical 9:16, estudante brasileiro 20-30 anos, expressão de dúvida controlada, camisa EPQ ou casual, estudando em mesa com notebook e caderno de questões, luz noturna suave, fundo escuro com viés azul marinho, composição assimétrica com espaço negativo superior 20% e inferior 20% para texto/CTA, paleta EPQ: azul marinho, azul elétrico, branco, sem neon exagerado, sem sorriso artificial, sem banco de imagem, espaço livre central para headline, render fotográfico, 8k.”

Negativos:
“genérico, sorriso publicitário, banco de imagem, neon excessivo, texto na imagem, logo pequeno, sobreposição de elementos poluente”

### Feed — Autoridade
Prompt base:
“Formato 4:5, professor ou especialista EPQ em sala de aula ou ambiente pedagógico, postura aberta, didática, foco no rosto e na explicação, iluminação natural mista com viés técnico azulado, fundo limpo com elementos discretos de grid EPQ, paleta oficial, logo EPQ preservado, sem excesso decorativo, render fotográfico.”

### Carrossel — Case
Prompt base:
“Formato 4:5, antes/depois de aluno em contexto de evolução, sem exagero, fotografia realista, expressão de confiança controlada, ambiente realista de estudo/sala, cores EPQ, tipografia overlay não incluída, espaço para texto institucional.”

### Reels — Método
Prompt base:
“Formato 9:16, sequência visual com aluno em movimento de estudo para aprovação, transição de esforço para resultado, atmosfera cinematográfica, luz noturna estudiosa, paleta EPQ, elementos gráficos técnicos discretos, espaço para texto na tela, narrativa visual em 3 passos.”

## 4. CONTROLE DE MARCA EM IA
- Sempre especificar paleta EPQ
- Sempre indicar espaço para texto
- Sempre proibir neon exagerado
- Sempre proibir banco de imagem
- Sempre proibir sorriso artificial
- Revisar saída contra checklist visual
